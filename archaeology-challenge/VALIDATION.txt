Scope
-----

and no previous machine learning. The revision explains learning from labelled
examples before training code, distinguishes scores from measured performance,
and gives explicit actions and editable answer locations. Arithmetic is retained
for precision/recall and Cyprus catalogue agreement. Optional labs supply working

are reported as no winner; name order chooses one only to continue reproducibly.

Scientific limits and retained audit
-----------------------------------
All 300 retained tells were originally 350 x 350 pixels. Negatives comprise 249
at 64 x 64 and 44 at 350 x 350. The separate rule using original dimensions alone
gets 110/119 validation labels correct (92.4%). This is not image-model accuracy
and does not prove which cues the classifiers use. Both pipelines receive common
64 x 64 RGB input; DINO enlarges it to 224 x 224 before frozen feature extraction.
Common resizing does not equalise ground resolution or remove every collection cue.
The teaching split has no verified geographic independence.

The audit retains whole-ranking AP and within-size results: the 350-pixel validation
group has 60 tells and nine negatives; AP is 0.996 for DINOv2 and 0.960 for colour/texture.
The 64-pixel group has 50 negatives and no tells, so AP is not reported for that group.
Cyprus lacks expert image-visibility labels, has only six selected pairs and includes
overlapping image areas. Neither large scores nor catalogue agreement establish
archaeological detection accuracy.
