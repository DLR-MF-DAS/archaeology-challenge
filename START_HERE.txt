FROM TELLS TO CYPRUS — FOUR-HOUR EO WORKSHOP

Participant notebook: archaeology_participants.ipynb
Instructor notebook:  archaeology_instructor.ipynb
Facilitation plan and teaching research: FACILITATOR_GUIDE.md

Open https://colab.research.google.com/ and choose File > Upload notebook.
No paid Colab plan, Earth Engine account, API key or guaranteed GPU is needed.
Run cells in order. Participants follow four runnable examples and optional
exploration prompts; the instructor version adds interpretation notes and saved outputs.

DEFAULT WORKFLOW

The notebooks contain frozen DINOv2-small embeddings, a pinned Cyprus catalogue,
and twelve real Sentinel-2 image chips with provenance. At first run they retrieve
a balanced 600-image Enki sample using about 73 MB of HTTP byte-range downloads.
The download uses original ZIP-directory offsets and verifies every member's CRC.
Decoded pixel hashes are then checked against the feature cache. No full 1.7 GB
training archive or 12 GB test archive is needed.

The optional feature-extraction cell recomputes DINOv2 embeddings. A free Colab T4,
when available, is sufficient; the cached default also works on CPU. The default
path does not require installing or downloading the neural-network checkpoint.

FOR A WORKSHOP WITH UNRELIABLE INTERNET

If your facilitator provides a prepared enki_workshop_sample.zip, upload it to the archaeology_workshop/ directory in the Colab Files panel
before running the Enki loading cell. Leave the filename unchanged. The notebook
checks and reuses it. Core package installation still needs internet unless those
dependencies are already installed. Locally, the notebooks can run without
network access once their dependencies and the sample ZIP are available.

KEEP THE INSTRUCTOR NOTEBOOK PRIVATE UNTIL THE DEBRIEF

The participant version includes runnable examples, optional explorations and checks.
These cover ranking metrics, a linear probe, validation-only model selection, and
the Cyprus catalogue audit. Participants also complete error and transfer reviews.

The instructor notebook is executed against real imagery and includes plots,
results, completed exercise code, facilitator guidance and an optional recipe
for refreshing the public Sentinel-2 sample. Scores are measurements from this
curated split, not promised performance on other archaeological landscapes.

SCIENTIFIC SCOPE

This is a new teaching split drawn from the Enki training archive. The six hundred
images contain 300 source-negative images and 300 source-positive images from
five RGB landscape categories. Explicitly masked and black-and-white positive
folders are excluded. Similar-image filtering removes some duplicates, but the
archive does not provide verified site identities or geographic grouping. The
holdout is therefore not a geographic-generalisation benchmark or a secure blind
competition. Source labels remain recoverable from the public archive.

Cyprus chips are 1 km windows at 10 m/pixel from 5 August 2024. They support an
interpretation and domain-shift exercise, not archaeological visibility ground
truth. Nearby background locations are unlabelled, not confirmed absences. The
notebooks explicitly avoid reporting detection accuracy for this sample.

EDITING AND VALIDATION

src/archaeology_challenge/runtime.py contains the shared helpers embedded in both notebooks.
build_notebooks.py generates the notebooks and embeds the prepared assets.
prepare_workshop.py and select_enki_sample.py record the data-preparation recipe.
check_notebooks.py checks metrics, submission ID alignment, duplicate handling and
notebook structure, and can execute the instructor plus a participant copy.

The .work/ directory contains preparation caches and validation artifacts. The
notebooks do not import these local scripts or depend on .work/ when shared.

For package installation and optional dependencies, see README.md.

Rebuild after editing (using the prepared assets already present):
  .venv/bin/python build_notebooks.py
  .venv/bin/python check_notebooks.py --execute

Regeneration clears saved outputs; the execution step restores instructor outputs.
The participant validation copy is written only under .work/.
